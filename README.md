# ساختار جدید پرتفولیو

```
index.html                 ← قالب اصلی (دیگر اطلاعات پروژه‌ها داخلش نیست)
image/                     ← تصاویر (مثل قبل)
projects/
 ├─ manifest.js            ← فهرست نام فایل پروژه‌ها (ترتیب نمایش/قبلی-بعدی)
 ├─ _template.js           ← قالب خالی برای پروژه جدید (روی سایت منتشر نمی‌شود)
 ├─ 01-logo-zist.js
 ├─ 02-workshop-from-zero-to-mastery.js
 └─ ... (یک فایل برای هر پروژه)
```

## افزودن پروژه جدید
1. `projects/_template.js` را کپی کنید → مثلاً `projects/12-my-project.js`
2. اطلاعات را پر کنید.
3. در `projects/manifest.js` نام `'12-my-project'` را به آرایه اضافه کنید.
4. commit و push کنید.

## ویرایش / حذف
- ویرایش: فقط فایل همان پروژه را عوض کنید.
- حذف: نام را از `manifest.js` بردارید (فایل را هم می‌توانید پاک کنید).

## عیب‌یابی
کنسول مرورگر (F12) هشدار می‌دهد اگر: فایلی پیدا نشد، id تکراری بود یا فیلد ضروری خالی بود.
